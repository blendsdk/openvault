Polish the application shell with the BlendSDK app launcher, a vault-dial brand mark and
favicon, a context-aware documentation link, and consistent vertical spacing for page headers,
project headers, and descriptions.

The launcher is the global navigation control at every viewport width. It lists Projects
everywhere, adds the current project's sections inside a project route, filters destinations
by search, and closes and clears its query on navigation. The top-bar Docs link opens the
matching guide in a new tab for the current screen. The account menu and desktop sidebar keep
their existing behavior.
