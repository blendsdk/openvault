## Gate rule

Every decision below names the options considered, the choice, the evidence, the strongest
counterargument, and the reopen trigger. A decision is not final until the user-visible
acceptance criterion it supports has an execution task and a test.

## Resolution Notes

**AR-3/7:** The project name is both the route and the API name. The provider resolves it once and exposes both `project.id` and `project.name`; pages never guess a ULID.

**AR-4/5:** The web client is generated from the browser controllers, not the CLI controllers. Both clients are checked by `pnpm api:check`, so a route or schema change cannot silently drift.

**AR-6/9:** The reveal value is never placed in a URL, storage, or a shared context. It is a local `useState` in the detail panel and is zeroed by dropping the reference; JavaScript strings cannot be wiped in place, so the UI minimizes lifetime instead.

**AR-11/15:** The consumers and audit pages are read-only. The scaffold and rotation workflows stay on the CLI, which keeps the destructive surface out of the browser.

**AR-20:** `style-src 'unsafe-inline'` is required because Fluent UI's Griffel runtime injects style elements. Scripts remain `'self'` only and there is no `unsafe-eval`.
