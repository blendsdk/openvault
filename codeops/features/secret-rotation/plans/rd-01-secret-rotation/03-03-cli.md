# CLI: Secret Rotation Workflow

> **Document**: 03-03-cli.md
> **Parent**: [Index](00-index.md)

## Overview

This specification owns the `ov rotation` command group. It composes the generated client, the
existing value reader, the secure file writer, and the existing table/time formatting. It does not
add a new transport.

## Architecture

### Current architecture

- Root groups are registered in `apps/cli/src/commands/index.ts`.
- `apps/cli/src/commands/secret.ts` shows the parser, option helpers, `readValue`, and output style.
- `apps/cli/src/commands/files.ts` provides `writeOutputFile`.
- The generated client exposes `client.secrets.listSecrets`, `updateSecretMetadata`, and
  `writeSecretValue`.

### Proposed group

```text
apps/cli/src/commands/rotation.ts   new parser and group
apps/cli/src/commands/index.ts      register rotationGroup
```

## Commands

### `ov rotation set <name>`

| Option | Required | Meaning |
|---|---|---|
| `--every-days` | yes | Integer 1–3650 |
| `--project` | yes | Project name |
| `--json` | no | JSON output |

Calls `updateSecretMetadata({ project, name, rotationIntervalDays })`. Prints the name, interval,
due date, and status. [AR-16, PAR-08]

### `ov rotation clear <name>`

Calls `updateSecretMetadata({ project, name, rotationIntervalDays: null })`. Prints the cleared
state. [AR-16]

### `ov rotation list`

| Option | Meaning |
|---|---|
| `--project` | Project name |
| `--due` | Due-soon or overdue |
| `--overdue` | Overdue only |
| `--limit`, `--cursor` | Pagination |
| `--json` | JSON output |

Calls `listSecrets` with `rotation: "policy"` by default, `"due"` or `"overdue"` when selected. The
table columns are Name, Status, Due, Interval, Last rotated. [AR-16, AR-19]

### `ov rotation status <name>`

Calls the normal list with `q=<name>` (no rotation filter); selects the exact name. Prints the
interval or “No policy”, due date, status, current version, and consumers (Compose project/service,
state, last seen). [AR-16, AR-20]

### `ov rotation rotate <name>`

| Option | Meaning |
|---|---|
| `--generate` | Generate a 32-byte base64url value |
| `--out FILE` | Write the generated value to a mode-`0600` file |
| `--expires-at ISO` | Optional version expiry |
| `--encoding utf8\|base64` | Value encoding; default `utf8` |
| `--stdin` | Read the value from stdin |
| `--from-file FILE` | Read the value from a file or fd |
| `--idempotency-key KEY` | Existing idempotency support |
| `--project` | Project name |

`--generate` is mutually exclusive with `--stdin` and `--from-file`. Without `--generate`, one of
`--stdin` or `--from-file` is required. The command calls `writeSecretValue` with the value,
encoding, optional expiry, and idempotency key. It prints the version id and the next due date; if
generated and `--out` is absent, it prints the value once and writes a warning to stderr. [AR-5, AR-17]

### Generator

```ts
import { randomBytes } from "node:crypto";

const value = randomBytes(32).toString("base64url");
```

The generated value is never logged, never written to the CLI credential store, and never included in
the JSON metadata output. `--out` uses the existing secure writer (mode `0600`, exclusive unless
`--force`, symlink rejection). [AR-17, PAR-08]

## Error Handling

| Case | Output | Exit |
|---|---|---|
| Missing `--generate`/`--stdin`/`--from-file` | “Provide --generate, --stdin, or --from-file” | 2 |
| `--generate` with input options | “--generate cannot be combined with --stdin/--from-file” | 2 |
| Interval out of range | API validation message | 2 |
| `--out` exists without `--force` | Existing file error | 2 |
| Policy/rotation denied | Existing 403/404 message | 1 |
| Server validation | Existing 422 message | 1 |

No command prints the value in an error, log, or JSON metadata path. [AR-17]

## Testing Requirements

- Parser tests for required options, mutual exclusion, interval bounds, and `--out`.
- Command tests against `FakeVault` or the CLI test adapter:
  - set/clear call PATCH with the correct body;
  - list calls the correct rotation filter;
  - status selects the exact name;
  - rotate sends the value, encoding, expiry, and idempotency key;
  - `--generate` produces 43 base64url characters;
  - `--out` writes a mode-`0600` file and prints no value;
  - errors never contain the value.
- Docs guard. [AR-25, PAR-11]
